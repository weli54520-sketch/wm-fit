# WM Fit

مدرب شخصي لجوال أندرويد. عربي، داكن، وبدون تسجيل دخول.

## وش يسوي؟
- يبني لك خطة تمرين أسبوعية حسب هدفك (تنشيف، تضخيم، لياقة) ومستواك، وفي الأيام اللي تختارها.
- 33 تمرين، كل واحد معه رسمة متحركة وخطوات وأخطاء شائعة.
- تسجّل أوزانك، ويقترح عليك متى تزيد.
- زر "ما أقدر": يسألك ليش، ويعطيك بديل لنفس العضلة، ويتذكره.
- مؤقت راحة يطلع على شاشة القفل.
- يحسب سعراتك وبروتينك وكاربك ودهونك ومويتك.
- تختار عضلات تركّز عليها، والمدرب يزيد مجموعاتها.
- خريطة إصابات (أمام وخلف): قوة الألم، وجديدة أو مزمنة. ويعدّل التمارين عشانها.

## الخصوصية
- **بدون حساب وبدون تسجيل دخول.**
- كل بياناتك داخل جوالك بس. ما فيه خادم، وما نرسل شي.
- النسخة الاحتياطية التلقائية مقفلة (جوجل درايف ونقل الأجهزة).
- النت يُستخدم للتحديث بس.

## تنبيه
WM Fit يعطي إرشادات عامة مبنية على أبحاث منشورة، وهو **مو بديل عن الطبيب
أو أخصائي العلاج الطبيعي**. راجع طبيبك قبل أي برنامج تمرين أو مكمل، خصوصاً لو
عندك مرض مزمن أو تاخذ أدوية.

## المصادر
الأرقام في التطبيق من مراجعات منشورة، وشاشة "المصادر" داخل التطبيق تعرض كل رقم
ومصدره (ACSM 2026، ISSN 2017 و2021، Iraki 2019، Mifflin-St Jeor 1990،
Hodgdon و Friedl 1999).
